Chapter 4
Research Objectives
This chapter defines the eight specific, measurable research objectives of the proposed system. Each objective is derived directly from a research gap identified in Chapter 3 and a research question from Chapter 1. The objectives are designed to be independently testable — each has a named target metric — yet collectively form an integrated system. Section 4.1 states the primary objective. Sections 4.2 through 4.9 detail each specific objective. Section 4.10 provides the complete gap-to-objective traceability matrix.

4.1  Primary Objective
Primary Objective
To design, develop, and evaluate a deployment-ready multi-agent, multi-model agricultural expert system for Indian smallholder farmers that integrates five specialist AI agents — disease diagnosis, nutrition deficiency, crop recommendation, weather and irrigation, and live market price advisory — orchestrated by an intent-routing backbone, grounded in a verified RAG knowledge base, augmented with farmer-facing explainability, and accessible via a multilingual Indic voice interface on a Progressive Web Application.

4.2  Specific Objectives
O1  Multi-Agent Orchestration Architecture
Description
Design and implement a LangGraph-based orchestrator that classifies incoming farmer queries into one of eight intent categories and dispatches inputs in parallel to the appropriate specialist agent(s). The orchestrator maintains multi-turn conversational state via Redis session memory and merges multi-agent responses into a single coherent advisory reply.
Gaps closed
G1 — No unified multimodal advisory session
Key technologies
LangGraph v1.1 · GPT-5.5 backbone · fine-tuned BERT-multilingual intent classifier · Redis session store · asyncio parallel dispatch
Target metrics
Intent classification accuracy > 95% · End-to-end response latency < 4 s (cloud) and < 8 s (PWA offline cache)

O2  Disease Diagnostic Agent
Description
Fine-tune ViT-L/16 with LoRA adaptation (rank-16, alpha-32) on a composite dataset of 164,500 leaf and pest images across PlantVillage, PlantDoc, and IP102. Integrate AgriChain Chain-of-Thought prompting for structured reasoning from visual input to treatment protocol. Generate Grad-CAM saliency maps for every diagnosis.
Gaps closed
G1 (image input modality) · G3 (Grad-CAM generated for rendering)
Key technologies
ViT-L/16 (ImageNet-21k) · LoRA rank-16 · LLMI-CDP dialogue style · AgriChain CoT · PlantVillage (87k) + PlantDoc (2.5k) + IP102 (75k)
Target metrics
Top-1 accuracy > 90% · F1 macro > 0.87 · Grad-CAM IoU vs. expert annotation > 0.75 · Covers 200+ diseases across 50+ crops

O3  Nutrition Deficiency Agent with Cross-Modal Fusion
Description
Develop a cross-modal fusion network that concatenates ResNet-50 leaf image feature vectors (2048-dim) with normalised real-time soil sensor readings (NPK, pH, EC, moisture — 6-dim) into a joint 2054-dimensional representation. Three fully-connected layers produce: (1) deficiency class label (N/P/K/Fe/Zn/B deficiency or healthy), and (2) fertiliser dose recommendation in kg/ha aligned with ICAR Soil Health Card norms.
Gaps closed
G2 — No cross-modal sensor + image nutrition fusion in a conversational loop
Key technologies
ResNet-50 encoder · 6-dim sensor vector (MQTT/REST) · Cross-modal MLP · ICAR Soil Health Card DB · SHAP feature importance
Target metrics
Deficiency class F1 > 0.85 · Fertiliser dose RMSE < 5 kg/ha · SHAP stability score > 0.80 across repeated runs

O4  Hallucination-Resistant RAG Knowledge Layer
Description
Build a 250,000+ document chunk RAG pipeline over verified ICAR Package of Practices (all major Indian crops), KCC call transcripts, CGIAR, FAO, Agmarknet historical data, and Soil Health Card norms. Implement hybrid BM25 + dense retrieval with E5-large-v2 embeddings, cross-encoder reranking, HyDE query expansion, and Qwen3-72B LLM-as-judge confidence gating. Escalate to KCC expert webhook if confidence score < 0.70.
Gaps closed
G1 (knowledge grounding across all five domains)
Key technologies
Qdrant vector store · E5-large-v2 embeddings · ms-marco cross-encoder · HyDE + MMR · Qwen3-72B judge · Bilingual Hindi+English index
Target metrics
RAGAS faithfulness > 0.88 · Context relevance > 0.85 · Hallucination rate < 5% · Expert escalation trigger accuracy > 90%

O5  Farmer-Facing Explainable AI (XAI)
Description
Render Grad-CAM saliency heatmaps as colour overlays on the farmer's uploaded leaf image and SHAP feature importance bar charts for crop recommendations — directly within the React PWA advisory response as farmer-accessible UI components, with Hindi-labelled axes and simplified visual legends. This closes the gap between XAI as a research output and XAI as a farmer-facing trust mechanism.
Gaps closed
G3 — XAI never rendered to the farmer in any deployed system
Key technologies
Grad-CAM (layer4) · EigenCAM (validation) · SHAP TreeExplainer · Recharts (PWA bar charts) · Hindi axis labels via i18next
Target metrics
Grad-CAM IoU > 0.75 vs. ICAR agronomist annotation · SHAP stability > 0.80 · Farmer comprehension score > 3.5/5.0 (Likert, n=30 pilot)

O6  End-to-End Indic Voice Advisory Pipeline
Description
Implement a complete voice advisory pipeline: Whisper large-v3 (fine-tuned on Indic agricultural speech from the 10,934-recording benchmark corpus) for ASR → multilingual RAG retrieval over Hindi+English bilingual knowledge index → Bhashini TTS for spoken response delivery in 10 Indic languages. The pipeline must operate within a 4-second end-to-end latency budget on 3G connectivity.
Gaps closed
G4 — No end-to-end Indic voice-to-advisory pipeline exists in any agricultural system
Key technologies
Whisper large-v3 (Indic fine-tuned) · Bhashini ASR + TTS API · IndicBERT NER · MediaRecorder (PWA browser) · 16 kHz mono WAV preprocessing
Target metrics
WER < 20% for Hindi agricultural speech · WER < 30% for five regional languages (Tamil, Telugu, Marathi, Kannada, Odia) · End-to-end latency < 4 s

O7  Live Market Price Advisory Agent
Description
Integrate Agmarknet and eNAM live mandi price feeds (15-minute refresh, Redis cache) with a Prophet-based 7-day price forecast model. Rank nearby mandis by Haversine distance and price differential. Co-deliver sell, hold, or transport-to-mandi advisory within the same conversational session as agronomic advice — enabling compound queries such as 'my crop has blight; should I treat or sell now?'
Gaps closed
G5 — Live market price never co-delivered with agronomic advice in any prior system
Key technologies
Agmarknet API · eNAM data feed · Prophet time-series forecast · CACP MSP dataset 2024–25 · Haversine mandi ranking · Redis 15-min TTL cache
Target metrics
7-day price forecast MAPE < 8% · Mandi ranking accuracy > 85% vs. actual best-price mandi · Sell/hold advisory agronomist agreement > 75%

O8  System Evaluation and Expert Validation
Description
Benchmark the complete integrated system on MIRAGE (multi-turn agricultural dialogue benchmark) and AgMMU (agricultural multimodal understanding benchmark). Validate advisory quality via a blind evaluation panel of ten ICAR-certified agronomists rating 200 real farmer queries across five crop categories on a 5-point Likert scale for correctness, clarity, safety, and actionability.
Gaps closed
Validates that all five gaps are closed — quantitative evidence for each claim
Key technologies
MIRAGE benchmark · AgMMU benchmark · RAGAS eval suite · ICAR agronomist panel (n=10) · Langfuse tracing · Ablation study framework
Target metrics
Agronomist correctness Likert > 4.0/5.0 · Agronomist agreement > 80% · MIRAGE score > baseline by 15% · Ablation: 5-agent vs. single-agent · RAG vs. no-RAG
